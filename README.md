# 🍽️ MealMate - Online Food Ordering System

MealMate is a web-based food ordering application developed using Django. It allows customers to browse restaurants, view menus, add items to the cart, place orders, and make secure online payments through Razorpay.

## 🚀 Features

- User Registration and Login
- Browse Restaurants and Food Items
- Add/Remove Items from Cart
- Order Placement and Tracking
- Razorpay Payment Gateway Integration
- Restaurant Management
- Responsive User Interface
- Order History

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript


### Backend
- Python
- Django

### Database
- MySQL / SQLite

### Payment Gateway
- Razorpay
